# Changelog

Release notes live on GitHub Releases: https://github.com/MikeBild/subkit/releases

Each release is cut from a tag. Its notes are generated from commit subjects since the previous
tag, so this file is not maintained by hand. Use `feat(user):` or `fix(user):` for a short,
user-facing release note. Other commits remain out of the notes. Read the commit history for why.
